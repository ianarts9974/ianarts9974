## 👋 About Me

Hi! I'm **Ian Kimemia (Ianarts)** — a growth-driven software developer and AI specialist building strong foundations in full-stack web engineering, backend architecture, and intelligent automation.

I enjoy understanding how systems work from the ground up — from database design, proxy routing, and RESTful APIs to crafting sleek, dark-themed glassmorphic user interfaces. When I'm not shipping code or evaluating machine learning models, I create fine art pencil and charcoal illustrations. My core focus areas include **Full-Stack Engineering, AI & Machine Learning, and System Automation**.

## 🎯 What I'm Focused On

- **Full-Stack & Backend Development** — Engineering scalable web platforms, REST APIs, and real-time systems
- **AI & Machine Learning (RLHF)** — Model evaluation, prompt engineering, and data preparation workflows
- **Python Automation & CLI Tooling** — Static code linters, event-driven file bots, and workflow automation

- **Modern UI/UX Architecture** — High-contrast, responsive, dark-mode interfaces with clean user flows
